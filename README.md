<h1 align="center">Airmai</h1>

<p align="center">在 iPhone、iPad 和 Apple Watch 上，查看成绩，发现歌曲，记录每一次出勤。</p>

Airmai 是为舞萌 DX 与中二节奏玩家打造的原生 Apple 平台应用。成绩、曲库、机厅和谱面工具，放在一起。

## 成绩，一目了然

- **成绩与 Rating**。查看个人成绩、舞萌 B50 和中二 R50，生成并分享成绩图片。
- **圆环与图表**。用三枚圆环查看 SSS、FC、AP／AJ 的完成情况，继续查看定数表现、等级分布、最佳成绩结构，以及接近下一个目标的歌曲。
- **歌曲详情**。查看封面、谱面难度、定数、个人成绩与收藏，快速找到谱面确认视频。
- **牌子进度**。追踪各版本牌子的完成情况，包括霸者。
- **多账号**。切换水鱼、落雪和 MuNET 账号，读取对应来源的成绩。通过更新页完成所选来源支持的同步流程。

## 从找歌，到出勤

- **曲库搜索**。按曲名、别名、版本和难度查找歌曲，结合分类与筛选缩小范围。
- **机厅地图**。查找附近机厅，查看距离、机台与营业信息，并打开导航。数据由 Nearcade 提供。
- **收藏品与回忆**。浏览称号、头像、姓名框等收藏品，查看数据来源提供的成绩记录。
- **常用工具**。单曲 Rating 计算、服务器状态、收藏歌曲和成绩管理。

## AirmaiDX

在应用内预览与游玩 simai 谱面，调整流速、镜像、时序与音量。使用 ADX 下载页检索谱面、批量下载、查看进度，并导出文件用于 AstroDX。

目录数据由 ADX 谱面资源提供，采用 CC BY 4.0。Airmai 对目录做筛选、排序、版本归类和别名整合。谱面、音频、封面及 PV 的权利归各自权利人所有。[来源与许可](https://adxdls.saop.cc/license)

## 在每一块屏幕上

- iPhone、iPad，以及 iPhone Duo 的内外屏与书本模式适配。
- Liquid Glass 与毛玻璃外观，支持自定义背景和小组件背景调整。
- 主屏幕与锁屏小组件、StandBy、实时活动和灵动岛。
- Apple Watch 上的“出勤！”记录与实时心率，手机端成绩同步。具备歌曲时间和对应心率记录时，在歌曲详情查看心率变化。

## 安装

| 方式 | 入口 | 使用说明 |
| --- | --- | --- |
| TestFlight | [加入 Airmai 测试](https://testflight.apple.com/join/GEN6DdpC) | 在 iPhone 或 iPad 安装 TestFlight，再打开邀请链接 |
| IPA | [GitHub Releases](https://github.com/finnoscar/airmai/releases/latest) | 下载 `.ipa`，使用自己的签名安装，具体步骤见安装说明 |

手机与平板需要 iOS／iPadOS 16.0 或更新版本，手表组件需要 watchOS 10.0 或更新版本。Liquid Glass 由支持该材质的系统提供。

GitHub 发布页会列出 IPA 的版本、构建号与 SHA-256 校验值。[安装说明](INSTALL.md)
